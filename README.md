# 🚀 Generative AI Learning Journey

## 📌 Overview

This repository documents my journey of learning **Generative AI (GenAI)**, including foundational concepts, hands-on projects, and practical implementations using modern tools and frameworks.

The goal is to build a strong understanding of:

* Large Language Models (LLMs)
* Prompt Engineering
* Retrieval-Augmented Generation (RAG)
* AI Agents
* Real-world GenAI applications

---

## 🧠 Topics Covered

### 1. Fundamentals

* What is Generative AI
* How LLMs work (Transformers, Tokens, Embeddings)
* OpenAI / HuggingFace models

### 2. Prompt Engineering

* Zero-shot / Few-shot prompting
* Chain-of-thought prompting
* Role-based prompts
* Prompt optimization techniques

### 3. Embeddings & Vector Databases

* Text embeddings
* Similarity search
* Vector databases (FAISS, Chroma, Pinecone)

### 4. RAG (Retrieval-Augmented Generation)

* Document loading & chunking
* Embedding storage
* Retrieval + generation pipeline

### 5. Agents & Tool Usage

* LangChain Agents
* Tool calling
* Multi-step reasoning workflows

### 6. Frameworks & Tools

* LangChain
* Langgraph
* OpenAI API

### 1. Clone Repository

```bash
git clone <your-repo-url>

```

### 2. Create Virtual Environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Set Environment Variables

```bash
export OPENAI_API_KEY="your_api_key"
```
